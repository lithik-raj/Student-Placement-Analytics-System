# Student Placement Analytics System

A full-stack **Student Placement Analytics System** developed to manage, analyze, and visualize student academic performance, placement information, technical skills, and career readiness through an interactive web-based dashboard.

## 📌 Project Overview

The Student Placement Analytics System provides a centralized platform for managing student placement-related information and presenting meaningful analytics through an interactive dashboard.

The system allows users to search and select individual students to view their academic performance, placement details, skills, and readiness information. An authenticated admin can update student, placement, and skill-related information.

## 🚀 Key Features

* Student-wise analytics dashboard
* Academic performance analysis
* Placement status tracking
* Company and package information
* Student skills management
* Skill proficiency tracking
* Career readiness analysis
* Student search functionality
* Interactive data visualization
* Admin authentication
* Admin-only data modification
* MySQL database integration
* Dynamic Flask web application
* Modern interactive dashboard interface

## 📊 Dashboard Modules

### 🎓 Academic Analytics

Provides student-specific academic information including:

* Student details
* Department
* Academic year
* CGPA
* Academic performance visualization

### 💼 Placement Analytics

Displays placement-related information including:

* Placement status
* Company name
* Industry
* Package in LPA
* Placement date

### 🧠 Skills & Readiness

Provides student-specific skill analysis including:

* Technical skills
* Skill proficiency
* Beginner
* Intermediate
* Advanced
* Expert
* Career readiness information

## 🗄️ Database

The application uses a relational MySQL database to manage:

* Student information
* Placement information
* Company information
* Skills
* Student skill proficiency

The database relationships allow the application to generate dynamic student-level analytics.

## 🔐 Admin Management

The system includes an authenticated admin interface that allows authorized users to:

* Update student information
* Update placement details
* Manage company information
* Add and update student skills
* Update skill proficiency levels

Regular users can view and search student analytics without modifying the data.
